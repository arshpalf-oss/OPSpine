OPSPINE — START HERE
====================

QUICK START
-----------
Run:  ./start.sh
Then open http://localhost:5000 in your browser.

The first run will create a Python virtual environment and install dependencies
(Flask, python-docx, python-pptx, openpyxl, reportlab, Pillow). This takes about
30 seconds. Subsequent starts are instant.

If you prefer manual setup:
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  python app.py

WHAT YOU GET
------------
  /dashboard     — Parent launcher with animated tool cards, motion presets
  /abyss         — Central AI router (holographic core)
  /scout         — Research & claim verification
  /forge         — Produce real PPTX/DOCX/XLSX/PDF/MD/PNG files
  /quill         — Writing canvas with AI transforms
  /kronos        — Natural-language calendar scheduling
  /whiteboard    — Node-based visual thinking canvas
  /dash          — Command center & shortcuts
  /working-board — Project execution canvas
  /library       — All your generated files and content
  /settings      — Identity, AI keys, backup/restore, motion presets

KEYBOARD SHORTCUTS
------------------
  ⌘K         Command palette (search everything)
  ⌘0         Dashboard
  ⌘1–8       Jump to a workspace
  ⌘Enter     Run the primary action in the current room
  ?          Show all shortcuts
  Esc        Close overlays
  ⌘\         Toggle navigation rail

OFFLINE BY DESIGN
-----------------
OPSpine runs fully offline with deterministic local engines. Add API keys in
Settings only if you want cloud AI — every feature works with zero keys.

DATA
----
  All data is stored in data/opspine.db
  Export a full backup from Settings → Data → Download Backup
  Restore works from the same JSON file
  No telemetry, no cloud, no accounts

TROUBLESHOOTING
---------------
- Port in use: PORT=8080 ./start.sh
- Reset everything: stop the server, delete data/opspine.db, restart
- Python not found: use python3 instead of python
- venv issues: rm -rf venv and run ./start.sh again
